# 05 · Interfaz y experiencia de uso

> 🟡 **Segunda pasada.** Los principios y el esqueleto están fijados; el detalle de cada pantalla se escribe junto con los mockups.

## Principios (decididos)

1. **Densidad alta de datos.** El analista quiere ver mucho a la vez. No se esconde información detrás de tres clics para que se vea limpio.
2. **Oscuro por defecto.** Se trabaja en salas de video. El tema claro existe y funciona, pero no es el que se abre.
3. **Teclado primero.** `Ctrl+K` abre el asistente desde cualquier pantalla. Navegación completa sin ratón.
4. **Todo exportable.** Cualquier tabla o gráfica se copia, se descarga o se manda a un informe.
5. **Una pregunta por pantalla.** Si una vista intenta responder dos preguntas distintas, se parte en dos.
6. **El dato dice de dónde vino.** Fuente y fecha visibles, no escondidas detrás del cursor.
