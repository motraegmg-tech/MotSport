# Entregables

Aqui viven las versiones entregables del producto y de sus documentos.

## Reglas

- Una carpeta por entrega: `MotSport-<version>-<destinatario>/`
- Documentos con nombre `YYYY-MM-DD_nombre_vN.pdf`
- Todo entregable final se copia tambien a Drive
- **Nada de esta carpeta se edita despues de entregado.** Si hay un cambio, es una entrega nueva
